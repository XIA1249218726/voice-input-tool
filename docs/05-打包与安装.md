# 打包与发布

## 1. 环境

| 工具 | 版本 | 用途 |
| --- | --- | --- |
| Windows | 10/11 x64 | 目标平台 |
| Python | 3.10+（推荐 3.12） | 运行 / 打包 |
| PyInstaller | 6.6+ | 生成 onedir exe |
| NSIS | 3.x | 生成安装程序 |
| SenseVoiceSmall int8 | 2024-07-17 | 离线模型（约 228 MB） |

依赖：`build/requirements.txt`；打包工具：`build/requirements-build.txt`。

## 2. 准备模型

模型不提交到仓库：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\download-model.ps1
```

脚本会下载、解压到 `models\sense-voice\`，并校验
`model.int8.onnx` 的 SHA256。

## 3. 打包便携版

```powershell
powershell -ExecutionPolicy Bypass -File build\build_app.ps1
```

脚本流程：

1. 自动选择 Python（`.venv` → `runtime` → PATH），也可用 `-PythonExe` 指定；
2. 调用 PyInstaller：

```text
python -m PyInstaller --noconfirm --clean --windowed --onedir ^
  --name VoiceInputTool --icon app.ico --version-file build\version_info.txt ^
  --add-data "app.ico;." ^
  --collect-all sherpa_onnx --collect-all sounddevice --collect-all pynput ^
  --collect-submodules requests --collect-data certifi main.py
```

3. 组装 `dist\语音输入工具\`：
   - exe 重命名为 `语音输入工具.exe`；
   - 复制 `app.ico`、`models\sense-voice`、`使用说明.txt`、`自检.bat`、
     `config.example.json`；
4. 清理测试产生的 `userdata`。

常用参数：

```powershell
# 使用指定 Python / 模型
build\build_app.ps1 -PythonExe C:\Python312\python.exe -ModelDir D:\models\sense-voice

# 已装好 PyInstaller，跳过检查
build\build_app.ps1 -SkipInstall
```

为什么用 `--onedir` 而不是 `--onefile`：

- 228 MB 模型放在 exe 外，避免每次启动解压；
- 启动更快；
- 安装程序本身负责压缩，不需要 onefile。

## 4. 生成安装程序

```powershell
powershell -ExecutionPolicy Bypass -File build\build_installer.ps1
```

产物：`dist\VoiceInputTool-Setup-1.0.0.exe`。

安装程序特性：

- 简体中文 Modern UI；
- `RequestExecutionLevel user`，安装到 `%LOCALAPPDATA%\Programs\VoiceInputTool`，不弹 UAC；
- 桌面快捷方式（默认勾选）、开始菜单、可选开机启动；
- 注册卸载信息到 HKCU；
- 安装前 `taskkill` 旧进程，支持覆盖升级；
- 卸载时询问是否删除 `%LOCALAPPDATA%\VoiceInputTool` 个人设置。

参数：

```powershell
build\build_installer.ps1 -Version 1.0.1 -Makensis 'C:\Program Files (x86)\NSIS\makensis.exe'
```

## 5. GitHub Actions 自动发布

`.github/workflows/release.yml` 在推送 `v*` tag 时自动：

1. 安装 Python 依赖；
2. 下载模型（约 228 MB）；
3. 构建便携版；
4. 安装 NSIS 并构建安装程序；
5. 生成 `VoiceInputTool-<version>-portable.zip`；
6. 创建 GitHub Release 并上传两个文件。

```powershell
git tag v1.0.1
git push origin v1.0.1
```

也可以手动触发 `workflow_dispatch`，输入版本号。

## 6. 常见问题

### `Bad text encoding: installer.nsi:1`

NSIS 对无 BOM 的 UTF-8 中文脚本会报错。确保 `build/installer.nsi` 是
**UTF-8 with BOM**：

```powershell
$c = [IO.File]::ReadAllText($path, [Text.UTF8Encoding]::new($false))
[IO.File]::WriteAllText($path, $c, [Text.UTF8Encoding]::new($true))
```

### `Internal compiler error #12345: error creating mmap ...`

NSIS 把临时文件写到 `%TEMP%`。`build_installer.ps1` 已把 `TMP/TEMP` 指向
`_build\tmp`；手工编译时也要设置。

### PyInstaller 后启动报 `ModuleNotFoundError`

检查是否漏了 `--collect-all`。本项目的动态导入点：

- `app/asr.py` 延迟导入 `sherpa_onnx`；
- `CloudAsr` 延迟导入 `requests`；
- `pynput` 运行时按平台加载后端；
- `sounddevice` 需要 `_sounddevice_data` 中的 PortAudio DLL。

### 安装包过大

模型 228 MB 是主要体积。安装包使用 NSIS solid LZMA，通常约 170 MB。
如果不需要离线模型，可以发布一个不含模型的「云端版」，让用户自行把模型放到
`models\sense-voice\`。

### 杀毒软件误报

PyInstaller 引导器 + 未签名 exe 容易被启发式误报。正式分发建议：

1. 购买代码签名证书，用 `signtool` 对 exe 和安装包签名；
2. 不要用 UPX 进一步压缩；
3. 在 README 说明 SmartScreen 的处理方式。

## 7. 版本号修改位置

发布新版本时同步：

- `app/paths.py` 的 `APP_VERSION`；
- `build/version_info.txt`（FileVersion / ProductVersion）；
- `build/installer.nsi` 的 `APP_VERSION` 与 `VIProductVersion`；
- `build/build_installer.ps1` 的 `-Version` 默认值；
- `README.md` / `CHANGELOG.md`。
