# 模块详解

## `main.py` —— 入口与自检

- 解析 `--selftest / --headless / --record / --version`；
- 单实例：命名互斥体 `Local\ValorantVoiceInput_Single`，第二次启动会查找已有窗口并置前；
- 崩溃处理：写 `logs/crash.log` 并弹 MessageBox；
- `--selftest` 检查 Python 版本、依赖、配置、模型、输入设备、管理员权限，并尝试加载模型；
- 打包成 windowed 程序后，CLI 模式会调用 `AttachConsole(ATTACH_PARENT_PROCESS)` 附着父控制台，
  没有父控制台时 `AllocConsole()`；同时把自检结果写入 `logs/selftest.txt`，供 `自检.bat` 显示。

所有 Win32 函数都显式声明 `argtypes/restype`，原因见“问题修复报告”。

## `app/paths.py` —— 路径解析

- `resource_root()`：exe 目录（frozen）或项目根目录（源码）；
- `data_root()`：按“环境变量 → portable.flag → LOCALAPPDATA → exe\userdata → TEMP”选择可写目录，
  用真实写探针判断，避免安装在只读位置后配置保存失败；
- `config_path/log_dir/model_dir/icon_path` 统一提供具体路径。

## `app/config.py` —— 配置

- `@dataclass Config`：所有可调参数，见 `03-配置项参考.md`；
- `load()`：读 JSON → 按默认值类型逐项 `_coerce` → `_sanitize` 限制范围；
- `save()`：同目录临时文件写入 + `fsync` + `os.replace` 原子替换；
- 安装版首次启动时，如果 exe 旁有旧 `config.json`，自动迁移到数据目录；
- 版本升级新增字段时，缺失字段自动使用默认值。

## `app/audio.py` —— 录音与音频处理

`Recorder`：

- 常驻一条 16 kHz / 单声道 / float32 的 `sounddevice.InputStream`；
- 回调按 100 ms 一块（1600 样本）处理，维护：
  - `_preroll`：未录音时最近 3 块（约 300 ms），避免吃掉第一个字；
  - `_chunks`：录音中的数据块，超过 `max_seconds` 停止追加并标记溢出；
  - `_level`：最近峰值，供界面/调试使用；
- `open()` 会解析设备关键字，找不到时回退系统默认，并记录 `device_missing` 与实际设备名；
- `start()/stop()` 在锁内切换状态，`stop()` 返回拼接后的 `np.float32` 数组。

`trim_silence(samples)`：

- 10 ms 一帧计算 RMS；
- 噪声底 = 10% 分位 RMS，门限 = max(0.006, 噪声×2.5)；
- 无活跃帧或有效语音 < 120 ms → `None`；
- 首尾各留 180 ms，峰值过小做最多 3 倍增益并 clip。

`to_pcm16()` / `to_wav_bytes()`：给云端接口和测试使用。

## `app/asr.py` —— 识别引擎

`LocalSenseVoice`：

- 用 `sherpa_onnx.OfflineRecognizer.from_sense_voice` 加载 `model.int8.onnx` + `tokens.txt`；
- CPU，线程数由配置决定，支持 `auto/zh/en/ja/ko/yue`；
- `transcribe()` 内加锁（sherpa 流不是线程安全的），并保证输入是连续 float32。

`CloudAsr`：

- 任意 OpenAI 兼容 `/audio/transcriptions`；
- WAV 直接内存编码，不落盘；
- 错误统一抛出 `AsrError`，服务层转成界面日志。

`clean_text()`：去掉 `<|...|>` 标签、压缩空白。

`build_engine(cfg)`：按 `cfg.engine` 选择本地或云端。

`postprocess(text, cfg)`：修正词 → 去句末标点 → 加前缀。

## `app/hotkey.py` —— 全局热键

- `HotkeyManager` 解析 `f8`、`v`、`ctrl+alt+v`、`mouse4/mouse5`；
- 同时监听键盘和鼠标（仅鼠标键时启用鼠标监听）；
- 修饰键用集合维护，按下时检查 `modifiers ⊆ _mods`，松开主键或修饰键都会结束；
- 用 `VkKeyScanW` 把字符映射成虚拟键码，兼容非美式键盘布局；
- 热键为单独修饰键时 `valid()` 返回 False；
- `capture_once()` 供界面“录制按键”使用，超时/未知键返回空串。

## `app/winapi.py` —— 输入注入

`SendInput` 结构体（MOUSEINPUT/KEYBDINPUT/HARDWAREINPUT/INPUT）完整声明。

- `type_text()`：把字符串拆成 UTF-16 码元，`KEYEVENTF_UNICODE` 按下+抬起；
  支持 `\n`（回车）和 `\t`；
- `tap_key()`：按下、短暂保持、抬起；
- `foreground_hwnd/foreground_exe/window_title`：用于“只在游戏内输入”；
- `is_admin()`：是否管理员；
- `set_clipboard()`：`GlobalAlloc` + `OpenClipboard`（重试 5 次）+ `SetClipboardData`；
  失败/异常路径都释放内存。

## `app/service.py` —— 业务状态机

- `start()`：一次性完成模型、麦克风、热键初始化，发布 `ready`；
- `stop()`：有序停止，带 worker join 和队列清理；
- `_begin/_finish_recording()`：状态切换、提示音、超时定时器、静音裁剪；
- `_work_loop()`：串行识别，保证不会同时跑两次推理；
- `preview()/record_test()`：界面上的“录音 3 秒并识别”；
- `game_active()`：前台进程路径子串匹配，支持分号/逗号分隔多个进程名；
- `_deliver()`：剪贴板 / 自动开聊天 / 逐字输入 / 自动发送，失败回退剪贴板。

## `app/gui.py` —— 界面

- DPI 感知（`SetProcessDpiAwareness(1)`），窗口居中；
- 状态灯 + 大字提示 + 日志面板；
- “使用”页：开始/停止、录音测试、把上次结果打到当前窗口；
- “设置”页：热键、麦克风、语言、ITN、本地/云端、输入行为、修正词、提示音、置顶；
- 保存时先落盘再重启服务；
- “打开配置文件夹”直接打开数据目录；
- 全局异常写到 `logs/crash.log`，避免 pythonw 下异常无声消失。

## `build/` —— 打包

- `build_app.ps1`：PyInstaller onedir + 组装模型/说明/自检；
- `installer.nsi`：NSIS 简体中文安装程序；
- `build_installer.ps1`：定位 makensis，生成 `dist\VoiceInputTool-Setup-1.0.0.exe`；
- `assets/`：安装包附带的 `使用说明.txt`、`自检.bat`、`config.example.json`。

## `tests/` —— 单元测试

`test_core.py` 覆盖配置校验/原子保存、静音裁剪、WAV 编码、文本后处理、
热键解析，以及（模型存在时）真实中文识别。共 17 个用例。
