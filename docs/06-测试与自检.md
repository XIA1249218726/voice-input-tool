# 测试与自检

## 1. 单元测试

```powershell
powershell -ExecutionPolicy Bypass -File scripts\test.ps1
```

或直接：

```powershell
python -m unittest discover -s tests -v
```

当前结果：**17 个用例全部通过**，覆盖：

| 测试类 | 内容 |
| --- | --- |
| `ConfigTests` | 默认值；错误类型转换；范围裁剪；原子保存往返；无临时文件残留 |
| `TextTests` | SenseVoice 标签清理；修正词/去标点/前缀；空文本 |
| `AudioTests` | 首尾静音裁剪；全静音返回 None；过短语音返回 None；WAV 头 |
| `HotkeyTests` | F8；鼠标侧键；Ctrl+Alt+V；单独修饰键非法 |
| `ModelTests` | 用 `models/sense-voice/test_wavs/zh.wav` 做真实离线识别（模型不存在时跳过） |

CI 不下载模型，因此 `ModelTests` 在 GitHub Actions 中自动跳过；Release 构建会下载模型并运行完整功能。

## 2. 自检

```powershell
powershell -ExecutionPolicy Bypass -File scripts\selftest.ps1
```

安装版：双击安装目录的 `自检.bat`，或运行
`语音输入工具.exe --selftest`（会附着父控制台）。

报告始终写入数据目录：

- 安装版：`%LOCALAPPDATA%\VoiceInputTool\logs\selftest.txt`
- 便携版 / 受限环境：`<程序目录>\userdata\logs\selftest.txt`

检查项：

1. Python 版本；
2. 资源目录、数据目录、运行方式；
3. `numpy/sounddevice/sherpa_onnx/pynput/requests`；
4. 配置（引擎、语言、热键）；
5. 模型文件与大小；
6. 输入设备列表；
7. 管理员权限；
8. 实际加载 SenseVoice 模型。

## 4. 手工功能清单（需要麦克风和游戏）

- [ ] 按住 F8 说“测试一二三”，松开后识别正确；
- [ ] 设置里把快捷键改成 `mouse4`，鼠标侧键可用；
- [ ] 组合键 `ctrl+alt+v` 可用；
- [ ] 只复制模式下，识别后剪贴板内容正确；
- [ ] 打开“仅在游戏窗口激活时输入”，切到桌面说话 → 只复制；切回游戏 → 自动输入；
- [ ] 关闭“自动发送” → 文字留在聊天框，可继续编辑；
- [ ] 调整“开聊天延迟”到 0.5，卡顿时不丢字；
- [ ] 修正词 `a大=A大` 生效；
- [ ] 语言切英文/日文/韩文/粤语各说一句；
- [ ] 拔掉麦克风后启动 → 界面明确报错，按钮回到“开始”；
- [ ] 第二个实例启动 → 不重复开窗，旧窗口置前；
- [ ] 关闭程序后重开，设置保持。

## 5. 排查

- 自检显示模型缺失 → 运行 `scripts\download-model.ps1`；
- 自检显示依赖缺失 → `pip install -r build\requirements.txt`；
- 自检显示麦克风 0 个 → 检查 Windows 隐私设置「允许桌面应用访问麦克风」；
- 崩溃 → 查看 `%LOCALAPPDATA%\VoiceInputTool\logs\crash.log`。
