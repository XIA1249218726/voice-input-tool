# 配置项参考

配置文件默认位置：

- 源码运行：项目根目录 `config.json`
- 安装版：`%LOCALAPPDATA%\VoiceInputTool\config.json`

界面点“保存并应用”会自动写入；也可以关掉程序后手工编辑（JSON，UTF-8）。
读取时会做类型转换和范围限制，写错类型不会导致崩溃。

## 触发

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `hotkey` | string | `f8` | 触发键。支持 `f1`~`f12`、单字符、`mouse4`/`mouse5`、`ctrl+alt+v` 组合 |
| `trigger_mode` | string | `hold` | `hold`=按住说话；`toggle`=按一下开始、再按结束 |
| `max_record_seconds` | float | `15.0` | 单次最长录音，1~60 秒，超时自动结束 |

## 识别

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `engine` | string | `local` | `local`=本地 SenseVoice；`api`=OpenAI 兼容云端 |
| `language` | string | `zh` | `zh` / `auto` / `en` / `ja` / `ko` / `yue` |
| `use_itn` | bool | `true` | 数字、日期规范化（如“三” → “3”） |
| `num_threads` | int | `4` | 本地识别 CPU 线程数，1~16 |
| `device` | string | `""` | 麦克风名称关键字（不区分大小写），空=系统默认 |

## 输入行为

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `auto_enter_chat` | bool | `true` | 输入前先按回车打开游戏聊天框 |
| `auto_send` | bool | `true` | 输入完成后再按回车发送；关闭则留在输入框 |
| `chat_open_delay` | float | `0.35` | 按回车后等待聊天框出现的秒数，0~5 |
| `char_delay` | float | `0.005` | 每字符额外停顿（秒），漏字时调到 0.01 |
| `send_delay` | float | `0.15` | 打完字到按发送之间的等待 |
| `only_when_game` | bool | `true` | 仅当前台进程匹配 `game_process` 时输入，否则只复制 |
| `game_process` | string | `VALORANT` | 前台进程路径的子串，可用 `;` 或 `,` 分隔多个 |
| `prefix` | string | `""` | 每条识别结果前追加的内容 |
| `strip_punct` | bool | `true` | 去掉句末标点（避免游戏聊天框出现句号） |
| `only_clipboard` | bool | `false` | 只复制到剪贴板，不模拟按键（零注入风险） |

## 其它

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `beep` | bool | `true` | 开始/结束提示音 |
| `always_on_top` | bool | `false` | 窗口置顶 |
| `replacements` | object | `{}` | 识别修正词，键=听错的词，值=正确写法；界面里每行 `错误=正确` |

## 云端接口

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `api_base` | string | `https://api.siliconflow.cn/v1` | OpenAI 兼容接口根地址 |
| `api_key` | string | `""` | API Key（只保存在本机配置） |
| `api_model` | string | `FunAudioLLM/SenseVoiceSmall` | 模型名 |

云端请求格式：`POST {api_base}/audio/transcriptions`，`multipart/form-data`，
字段 `file`、`model`、`response_format=json`，可选 `language`。

## 手工配置示例

```json
{
  "hotkey": "ctrl+alt+v",
  "trigger_mode": "hold",
  "device": "HECATE G2",
  "language": "zh",
  "only_when_game": true,
  "game_process": "VALORANT;RiotClientServices",
  "replacements": { "哎大": "A大", "b小": "B小" },
  "beep": true
}
```

未写出的字段自动使用默认值。
