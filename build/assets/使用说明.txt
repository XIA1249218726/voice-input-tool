语音输入工具 1.0.0 —— 使用说明
================================

一、这是什么
    按住一个键说话，松开后语音自动变成文字，并输入到当前游戏/软件的
    聊天框里。语音识别完全在本机离线完成（SenseVoice 模型），
    不联网、不需要账号、不上传录音。

二、第一次使用
    1. 双击桌面「语音输入工具」，或在开始菜单里打开。
    2. 切到「设置」页，把「输入设备」选成你的真实麦克风
       （例如 HECATE G2），点「保存并应用」。
    3. 进游戏，按住 F8 说话，松开；文字会自动进入聊天框。
       如果默认快捷键不是 F8，右上角会显示当前快捷键。

三、游戏里打不出字怎么办
    关闭程序后，右键「语音输入工具」→「以管理员身份运行」再试。
    原因是游戏进程权限比普通程序高，Windows 会拦截普通程序的按键注入。
    如果仍然不行，把「仅在游戏窗口激活时输入」关掉再试。

四、设置与数据在哪里
    配置文件：%LOCALAPPDATA%\VoiceInputTool\config.json
    崩溃日志：%LOCALAPPDATA%\VoiceInputTool\logs\crash.log
    自检报告：%LOCALAPPDATA%\VoiceInputTool\logs\selftest.txt
    在「设置」页点「打开配置文件夹」可以直接打开这个目录。

五、常见问题
    1. 松开快捷键没反应
       - 快捷键可能被其它软件占用，换一个键；
       - 麦克风选错（选成 MIXLINE 等虚拟声卡），重新选择真实麦克风；
       - 点「录音 3 秒并识别」测试录音和识别链路。

    2. 识别不准
       - 说话稍慢、离麦近一点；
       - 在「设置 → 识别修正」里加一行「听错的词=正确的词」；
       - 环境噪音大时降低麦克风增益或开启降噪。

    3. 想省 CPU / 用云端识别
       设置 → 识别引擎 → 云端接口，填入任意 OpenAI 兼容接口地址、
       API Key 和模型名。注意：使用云端时录音会上传到该服务商。

    4. 会不会被反作弊封号
       程序只做两件事：录音、用 Windows 标准接口（SendInput）模拟
       键盘输入，不读内存、不注入进程、不改游戏文件。但第三方输入注入
       在各家反作弊里属于灰色地带，请自行评估风险。想零风险就勾选
       「只复制到剪贴板，不模拟按键」。

六、卸载
    开始菜单 →「语音输入工具」→「卸载 语音输入工具」，
    或 Windows 设置 → 应用 → 语音输入工具 → 卸载。
    卸载时会询问是否删除个人设置。

七、自检
    双击安装目录里的「自检.bat」，会检查依赖、模型、麦克风和权限。
